# PhishCatch - Backend API

API RESTful de Análisis Dinámico de Enlaces e Inspección Forense de Correos para la Prevención de Phishing.

Este repositorio contiene el código fuente del backend (servidor) de PhishCatch. Provee la infraestructura y los endpoints necesarios para orquestar consultas a motores de inteligencia de amenazas (OSINT), extraer metadatos de archivos de correo (.eml), manejar la autenticación de usuarios y gestionar el almacenamiento en base de datos.
